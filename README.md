## 📄 Requisito para Exportación de PDF (Rotativa)

Para habilitar la exportación de documentos a PDF en el entorno local:

1. Descargar el ejecutable `wkhtmltopdf.exe` desde la [Sección de Releases del proyecto](https://github.com/HeriJosue123/Proyecto_Final_VITALIA/releases).
2. Colocar el archivo en la ruta del proyecto: `wwwroot/Rotativa/wkhtmltopdf.exe`.
